Breakpoint behavior

  • Phone (<576px) — No mailbox rail. One pane: list ↔ detail. ☰ = folders overlay.
  • Tablet (576–991px) — Same master-detail as phone. Folders via ☰ overlay only.
  • Small desktop (992–1399px) — Master-detail; collapsed folder rail (48px) + ☰ for full panel.
  • Desktop (≥1400px) — 3 columns: folders 16rem + list 24rem + detail flex.
